# WPE Journal

A hand-coded static website journaling real Silliman University events I attended across the **5Cs of Silliman education** — Classroom, Church, Cultural, Court, and Community.

**GE 10 (Whole Person Education) final project** · Silliman University · 2024 · *my first web project.*

## Preview

View it live: **[https://jlumi382.github.io/ge10-journal/](https://jlumi382.github.io/ge10-journal/)**

- Homepage → 5 category pages → **39 individual event write-ups**
- Each entry: organizer, venue, date, photo proof, and a short personal reflection
- Full summary: [`jumawanWPEJournalSummary.pdf`](jumawanWPEJournalSummary.pdf)

## Why a journal?

A course project isn't a product — it's an exercise. The point of GE 10 is whole-person growth, which at Silliman means getting involved beyond the classroom. The project requirement was simple: **participate, then document it.** I chose a website over a paper journal because I'd been meaning to learn web development anyway — so the journal served two purposes at once: recording my events *and* teaching me the fundamentals in a project with a real deadline.

## What's in it

- **5 categories, 39 events** — classroom (8), church (8), cultural (10), court (8), community (5)
- **Per-event pages** — organizer details, venue, date, thumbnail, and a photo as proof of participation
- **Personal reflections** — a short write-up per event on what I took away from it
- **A consistent design** — one shared stylesheet, color themes per category, and a no-scroll, media-query-tuned layout

## Hand-built, zero frameworks

The point was to learn web development from the ground up, so there are no frameworks, no build tools, and no CMS behind it:

- **Plain HTML + CSS + JavaScript** — every page written by hand
- **Flexbox layouts** — the whole site is structured with Flexbox and responsive media queries
- **Static hosting** — served as-is on GitHub Pages; open the folder and it just runs

## Built with

| What | Used for |
|---|---|
| HTML | page structure for every category and event |
| CSS | theming, Flexbox layout, responsive media queries |
| JavaScript | small interactive touches (e.g. context-menu guard) |
| GitHub Pages | static hosting and deployment |

## Run it locally

1. **Clone or download** this repository.
2. **Open `index.html`** in any browser — no server or dependencies needed.

Or just visit the live site: [jlumi382.github.io/ge10-journal](https://jlumi382.github.io/ge10-journal/).
